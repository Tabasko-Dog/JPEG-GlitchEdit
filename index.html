Click a byte and type hex digits (0–9, A–F), or click in the text column and type characters. Drag (the list scrolls at its edges) or hold Shift with the arrow keys to select a range, then use Randomize selection. Backspace restores original bytes. Press Ctrl+/ or the Keys button for every shortcut, including nudging bytes with Alt+↑ and Alt+↓. Amber underlines may garble the image, red ones will likely stop it decoding.

Save re-processed JPEG

Re-decodes the current preview and exports a clean JPEG. Useful for normalising a glitched image or sharing it. CSS view filters/rotation are not baked in.

Export timelapse

Records a WebM timelapse from your edit history. No saved states are required.

Keyboard shortcuts

These work while the hex view has focus. Press Esc to clear a selection, and Esc again to leave the hex view so Tab moves on.

Editing
